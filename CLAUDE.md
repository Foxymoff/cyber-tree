# Кибер-дерево знаний

Арт-объект для дня первокурсника. Студенты по QR отправляют пожелания, те после модерации прилетают светящимися листьями на дерево, выведенное на плазменную панель.

Полное ТЗ: `docs/spec.md`. Перед работой над любым этапом прочитай соответствующий раздел.

## Стек

- Next.js (App Router) + TypeScript
- PixiJS v8 — визуализация дерева
- Neon (Postgres) через `@neondatabase/serverless`
- Деплой на Vercel

## Команды

```bash
npm run dev            # локальная разработка
npm run build          # сборка, обязательно прогонять перед коммитом
npm run lint
npm run db:migrate     # применить миграции к Neon
npm run shot           # скриншот /display в /tmp/display.png (Playwright)
```

## Чего не делать

- **Вебсокетов нет.** Serverless-среда не держит постоянные соединения. Всё обновление данных — опросом раз в 2 секунды через `updated_at`-курсор. Не предлагать Socket.IO, SSE или Pusher.
- **Состояния на сервере нет.** Между запросами в памяти ничего не живёт. Никаких модулей-синглтонов с кэшем, никаких очередей в памяти.
- **Файловой записи нет.** Только Neon. Ни SQLite, ни JSON на диске.
- **PixiJS на сервере падает.** Импортировать только динамически, `dynamic(() => import(...), { ssr: false })`.
- Не публиковать ничего автоматически. Автомод только выставляет `auto_flag`, решение всегда за человеком.
- Не ставить ограничений по IP. У мобильных операторов сотни абонентов за одним адресом.

## Переменные окружения

```
DATABASE_URL=      # строка подключения Neon
ADMIN_PASSWORD=    # общий пароль для /admin
```

Локально в `.env.local`, на проде — в настройках проекта Vercel.

## Конвенции

- Специальности — только из `config/specialties.ts`. Не хардкодить нигде больше, от длины списка зависит число веток дерева.
- Цвета — только из токенов, заданных в разделе 8 ТЗ. Не изобретать новых по ходу.
- Генерация дерева детерминированная, от seed. Один seed = одно дерево, иначе визуал не отладить по скриншотам.
- Интерфейс на русском. Комментарии в коде на русском.
- Формулы и математику писать простым текстом, без LaTeX.

## Порядок работы

Этапы перечислены в разделе 10 ТЗ. Идти строго по ним, по коммиту на этап, не браться за следующий, пока предыдущий не работает.

Перед тем как писать код — план. Перед коммитом — `npm run build`.

## Доводка визуала

`npm run shot` кладёт скриншот дерева в `/tmp/display.png`. Открывай его и смотри. Оценить по коду, красиво ли получилось, нельзя — только глазами, и повторять, пока не станет хорошо.
